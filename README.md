# Password Generator

A simple Python-based password generator that creates random passwords using letters, numbers, and special characters.

## Features

- Generates random passwords
- Allows the user to choose the password length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Handles invalid input

## Technologies Used

- Python
- Random module
- String module

## How It Works

1. The user enters the desired password length.
2. The program creates a collection of letters, numbers, and special characters.
3. The program randomly selects characters.
4. The selected characters are combined into a password.
5. The generated password is displayed.
